## 瀏覽器 E2E 實測

使用既有 Site 的受管預覽 `http://terminal.local:4173/`，在授權的 cloud browser 載入 WIRE-R7。實際 DOM 顯示「配線修訂 07 · 電路追查」及「無法啟動 3D 畫面」。點擊「重新載入」重試一次，結果相同。

瀏覽器於 14:48:06 UTC 記錄：

```text
THREE.WebGLRenderer: A WebGL context could not be created.
GL_VENDOR = Disabled, GL_RENDERER = Disabled, Sandboxed = yes
ErrorMessage = BindToCurrentSequence failed
THREE.WebGLRenderer: Error creating WebGL context.
createScene (src/scene.js:9:16)
```

這是啟動前提失敗，無法據此判定下列互動驗收成功或失敗，也不以 Node 結果代替。未修改瀏覽器安全設定、未用替代 renderer 冒充 3D 驗收。
