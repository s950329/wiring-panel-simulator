路由、材質及事件檢查使用真實 Three.js 模型與 Node 介面。22 條周邊線案例驗證新增與反向連接；開闔使用另建的共用端子案例，並保留既有全部 36 個操作板端子的開闔回歸。

**瀏覽器 E2E 尚未通過。** 前一版受管瀏覽器兩次啟動均因 WebGL renderer 停用失敗，細節見 [既有 E2E 阻擋記錄](electrical-acceptance.md)。本次未以 Node 驗證代替實際畫面驗收，也未改動瀏覽器安全設定。待可用 WebGL 環境補跑下列情境及既有電路流程：

- 有周邊接線時，以 UI 連接 TB1:42B → HL4:2，開闔可支援的盤面配置。
- 從按鈕下載 JSON，核對失敗端點、當前接線與模擬；網站及離線 HTML 均可下載。
- 收合操作板，目視四顆指示燈的手動與供電亮滅。
- 點線／接線列查看顏色及慢速閃爍；切換、取消、追查、刪除及系統減少動態效果。

重新整理會清除尚在舊頁面的接線。檢查新版時宜保留原頁另開分頁；新版提供匯出但尚無匯入。
