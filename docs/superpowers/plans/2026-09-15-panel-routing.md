# 操作板雙姿勢走線計畫

目標：修復使用者 11 線與 R8 23 線可接完卻不能收合的共同原因。接線只有在展開、收合均找到通過原有淨空驗證的完整路徑集合後才成立。

已確認原因：單線貪婪規劃鎖死較早電線、總線數影響候選高度、端子出口只保留第一個解、搜尋超限被誤報為淨空不足。2026-09-15 使用者已確認本方向並授權調整。

架構：單線 router 提供穩定候選與可辨識的搜尋診斷；群組 planner 優先保留有效路徑，遇衝突在有界搜尋內協調線序與候選；controller 在暫存姿勢完成兩套解，恢復現況後一次提交。開闔重用且重新驗證已求得解。

全域約束：不改端子、幾何基準、電氣拓樸、線距、操作板半平面或自交規則。線序、ID、選取、復原與失敗交易一致。快取不得跳過新障礙物。完整翻轉過程的線材物理不在本次範圍。

1. 加入 11 線 fixture 及可重現失敗的兩姿勢與交易回歸，先確認 RED。
2. 實作穩定單線候選及搜尋診斷、型別化群組規劃器。
3. 接入新增接線／移動操作板的雙姿勢交易與驗證快取。
4. 驗證 11／22／23 線、前綴、順序／方向變化、刪除重接、多次開闔、障礙回滾；保留既有 185 項測試。
5. 獨立審查、完整測試及離線／網站建置，同步 GitHub、發布同一 Site 的 R17。

每個完成階段記錄實際驗證結果；不以擴大搜尋上限或單一案例重新排序當成修復。
