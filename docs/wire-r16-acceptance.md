# WIRE-R16 固定電源進線驗收

## 結果

預設 BOARD 024 已將單一 MAIN 至 QF1 三個輸入端設定為設備預接線；新盤 QF1 OFF、練習線為零。固定電源線與 MC→TH 的三條銅片共同參與求解，可由固定清單查閱，不能從練習接線的刪除／復原入口移除。

`configuration.fixedConnections` 是可選、明示的端點陣列。正常驗證拒絕不存在端點、自接、雙向重複、與固定銅片或使用者線重複及超量。自訂盤可明示空陣列；runtime 與 solver 不依元件名稱或外觀補電。

缺新欄位且完整結構符合舊 stock BOARD 024 的專案，在匯入邊界補固定進線並回報說明。忽略名稱、操作狀態、參數和陣列顺序；型號、ID、位置、板體與其他結構必須相符。只將完全相同的旧手動進線歸入固定配置，控制線與其他錯接均保留。舊快照轉換規則不變。

## 驗證

- `npm test`：185 項全過，包含 strict TypeScript、既有幾何基準、原生走線、操作板開闔、匯入交易、單一來源及電性回歸。
- 新增 6 項固定進線測試：預設供電與 QF 隔離、固定線不可刪、契約與改名設備、舊檔精確遷移、自訂盤不補電、實際 22／25 線匯入及再匯出。
- 原始 22 條課堂控制線不改端點，實際 controller 驗證啟動、自保持、停止、過載警報、復歸、斷電及復電不自行重啟。
- 舊 25 線案例含反向表示的三條進線，實際匯入後只有 22 條練習線與六條固定線，綠燈正常啟動。
- 完整 A04 範例為 28 條盤內線、3 條馬達外接線及六條固定線；完整啟停、缺相、保險絲、QF 隔離、改名與往返匯入測試通過。
- Sites build helper 完成 `npm run build`，包含離線 HTML、內嵌腳本語法及逐位元組檢查。既有 Vite 大型 chunk 提示仍在，沒有建置錯誤。
- 獨立程式審閱無阻擋問題；其一般化提示文案建議已採用。

依使用者要求未執行 WebGL 或瀏覽器視覺驗收；既有元件幾何與端子座標未變。任意自訂固定線以端點清單呈現，本次未增加自訂預接線的 3D 路由；原有電源電纜外觀保留。
