# 第五題：外觀模型核對版 Q5-MODEL-V1

## 範圍

本次依使用者 22 張照片（IMG_4592 至 IMG_4613）及提供的《工業配線丙級技術士技能檢定術科測試應檢參考資料》實體 PDF 第 64–67 頁（印刷 62–65）建模。題號是 **01300-104305B，裝置配線第五題：二台抽水機交替運轉控制**，不是故障檢修 A5。

新增獨立 `/q5.html` 外觀核對頁；沒有改動現有預設盤面、元件庫或電路求解器。源碼延續 PR #3 的自訂盤面分支，不合併或覆蓋該分支。

## 已建立

22 個可選物件：MCCB、F1/F2、MR、MC1/MC2、TH-RY1/TH-RY2、FS、TB1/TB2/TB3、照片額外的 TB-FS/TB-E、電極棒、PE、三盞指示燈、COS1/COS2、BZ。型號可見者包括 NF100-SN、S-P21、TH-P20、CT-FB101LA、G4Q-212S、61F-G/61F-11、PLR-30。

FS 為一套液面控制器，61F-11 是其模組。前排 Ta/Tc/Tb/E2/E1、後排 S0/S1/S2/E3 共九端子。未接線的 S1 仍保留。

幾何描述為純 TypeScript，Three.js adapter 專責顯示。支援旋轉、縮放、整體／俯視／操作正面、選取、單獨檢視、端子狀態提示及描述 JSON 匯出。

## 不確定性及補拍

1. MR：需底座端號、型號或同型備品／接腳圖。八個位置並非已驗證的底座 1–8 腳。
2. MC/TH：線圈與深層輔助接點、TH 四個控制端子的標字受線材遮蔽。不要把常見端號套用為已確認事實。
3. COS：需背面端號或接點配置圖，確認檔位與接線端子的關係。
4. 電極棒：需確認三支棒與 E1/E2/E3 導線的實際對應。
5. 紅燈：照片右側貼 RL1；教材配置圖為左 RL1、右 RL2。保留 RED-LEFT/RED-RIGHT 物理身份，logicalRole=null；不靜默交換。

示範盤標示勿拆，補拍不要求拆線、拆底座或通電；同型備品／原廠接點圖可替代。

## 尺度與限制

板材採教材標稱值：底板 480×350×2 mm，內摺 25 mm；操作板 270×350×2 mm。元件尺寸、間距、孔位及端子坐標都是照片比例近似，非實測 CAD。照片額外的 9P/3P 轉接台保留但不混作教材 TB3。無塑膠線槽，不憑空新增。

模型沒有既有線束拓撲，沒有接線編輯、通電模擬、水位互動、交替動作或過载驗證。所有端子 wiringEnabled=false。positionVerified 只表示該區域／面可從照片辨識，並非坐標已量測。JSON 不是現行模擬器的專案匯入格式。

未來功能應遵照教材：手動 M + A/OFF/B 選泵；自動低水位啟動、滿水位停止並交替、下一次低水位換另一泵；MR 初態可為任一側；個別過載停該泵、BZ 響，復歸後按原條件恢復。不能自行加入過載自動換泵。

## 驗證

本地純模型 strict TypeScript 與 13 項 Node 測試通過。`Verify Q5 visual model` CI 使用專案 Three.js 0.180.0 依賴，執行 npm ci、全專案 typecheck、13 項新增測試與正式／既有離線建置。CI 實際結果另以該提交的工作流程為準。

附交付的單檔 HTML 以同一 TypeScript 來源另行打包；受本地依賴取得限制，僅該單檔使用環境既有 Three.js r140，不更動專案 0.180.0 依賴。瀏覽器窄版測試不等於實機 iOS 驗收。原始照片、PDF、生成預覽、模型匯出與字型不推送公開 GitHub。
