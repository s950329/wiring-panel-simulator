# 工業配線丙級第七題盤面模型

本盤面依 2026-10-03 提供的 16 張實物照片建立，並以題目元件表作名稱與代號基準。

## 已確認

- Q1：電動機斷路器，照片外觀為 Schneider GV2ME 系列；模型保留三極進出端與正面跳脫電流旋鈕。
- Q2：二極斷路器，照片可見 Schneider iC60N、C3 標示；模型使用二極進出端。
- KM1 / KM2：照片為成對白／黑色接觸器，上方各有輔助接點模組，中間有機械連鎖。模型以 TeSys D 類型外觀建立，兩顆共用同一 definition。
- 操作板：PB1–PB4 與 WL / YL / RL / GL 共八顆，沿用既有按鈕與指示燈模型。
- TB1 / TB2 / TB3：沿用既有端子台生成器；TB2、TB3 新增 4 組短端子台 definition。

## 刻意保留的不確定性

照片不足以可靠讀出 KM 上方輔助接點模組的完整原廠型號與所有端子標號，因此目前只建模題目電路會用到的 1NO（13–14）與 1NC（21–22），不把不可辨識的端子猜成已確認規格。

Q1 的可調跳脫電流旋鈕目前是幾何呈現；電性 solver 仍只模擬斷路器 ON/OFF，不模擬實際過載曲線、瞬時跳脫或額定電流。這與目前模擬器「離散教學、不計算真實保護時間」的邊界一致。

`question-07-empty.project.json` 是空盤配置，不預接題目答案；學員接線仍由 `connections` 建立。
