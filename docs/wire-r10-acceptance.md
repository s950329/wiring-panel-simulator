# WIRE-R10 指示燈對比驗證

日期：2026-09-14。

四顆 HL 指示燈統一採用低亮度、低反射的熄滅外觀；亮燈時保留原本色相，提高燈罩顏色與自發光。手動測試及電路模擬使用相同顯示邏輯。

| 驗證 | 結果 |
|---|---|
| `npm test` | 104 項通過、0 失敗、0 跳過，含 strict TypeScript |
| 四顆燈初始與熄滅 | 基底線性亮度低於原色 10%，自發光為 0；熄滅後完整還原材質 |
| 單燈點亮 | 四種燈色各自測試；最高基底色通道至少 0.9，材質亮度指標超過每顆未亮鄰燈 10 倍；其他燈材質不變 |
| 實際模型 | 燈罩共用的可見材質均套用更新，按鈕材質不受影響；既有幾何與端子基準通過 |
| 紅燈電路 | CONTROL L／N 接至 HL3，送電提高自發光，黃／綠鄰燈維持熄滅；斷電完整還原 |
| 環境反射 | 燈罩明確綁定既有場景 environment，確保 Three.js 使用個別材質的 envMapIntensity，避免場景設定覆蓋亮滅反射差異 |
| JSON 相容與錯誤保護 | 接受 WIRE-R8／R9／R10；匯出補充表面材質資訊；匯入失敗也完整保留原本亮燈的色彩、光澤與反射設定 |
| 獨立唯讀審查 | 發現並修正環境反射覆蓋問題；複查通過，無剩餘可行動問題 |
| `npm run build` | 成功；網站與離線 HTML 同為 WIRE-R10，內嵌程式語法及逐位元組一致，四張銘牌材質內嵌 |

亮度指標為真實 Three.js 材質的線性色彩與自發光計算，並非螢幕像素量測。測試包含真實盤面模型及模擬控制器。
