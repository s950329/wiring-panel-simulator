# WIRE-R12 電路模擬操作

此配置只用於離散教學；TH 的 TC–TB 是明示常閉假設，未核對真實額定電壓、電流或保護時間。

1. 保持「未送電」，展開操作板，切到「接線模式」。選元件，再點起點與終點端子；CONTROL、MAIN、M1 使用右側外接卡片。
2. 按下表逐條接線。PB3 的穩定 ID 1／2 顯示為 13／14；PB5 的 3／4 顯示為 21／22；ES1 的 1／2 顯示為 21／22。端子讀值會保留實際 ID。
3. MC1 主極到 TH1 的三條組裝銅片已明示列在「固定組裝連接」，不需再加線。每條新增的盤內線有 W 編號，外接線有 E 編號。
4. 選 QF1 切到 ON，勾選控制電源及主電源，按「送電模擬」。選 PB3 按住再放開：MC1 應保持吸合，HL4 供電，M1 三相供電成立。
5. PB5 停止、ES1 急停或 TH1 TEST 會中斷保持回路。急停及 TH 必須分別復歸，復歸後再按 PB3 啟動。
6. 展開「供電原因與端子定位」中的原因卡片，點端子查看相連電源及高亮導線。高亮包含分支，不代表電流方向；「顯示全部」可清除高亮。
7. 修改、刪除或復原接線前先按「停止模擬」。短接、未知端子或無法收斂會暫停並清除輸出；停止、修正，再重新送電。

## 可檢查的結果

| 操作／變更 | 預期教學結果 |
|---|---|
| PB3 按下再放開 | AP1 的 NO 支路保持 MC1；M1 供電獨立判斷 |
| 停止後移除 AP1:54 → PB3:2，再送電 | PB3 按住吸合，放開釋放；原因提示檢查保持支路 |
| 停止後移除 TH1:6/T3 → M1:W，再送電及啟動 | MC1 可吸合，但 M1 顯示缺相 |
| 只關主電源，再恢復 | 控制保持仍可存在；主電源恢復可重新供電 |
| 關控制電源，再恢復，未按 PB3 | 線圈已釋放，不自行恢復保持 |
| 急停／TH TEST 後停止模擬 | 急停鎖定／TH 跳脫保留，須各自復歸 |
| 送電中展開或收合操作板 | 接線端點與電性不因幾何移動而改變 |

指示燈的亮光位於操作板正面，請收合操作板查看。四顆指示燈熄滅時保留可辨識的白、黃、紅、綠底色且不發光，亮起時增加適量發光，以保留燈色與燈罩層次。未送電時可使用元件的手動亮燈測試；送電模擬時由實際回路決定亮滅。

點選導線或右側接線列後，該線呈桃紅／白色慢速閃爍，其他線淡化；證據追查使用青色。系統偏好減少動態效果時，保留高對比顏色並停用閃爍。

按右側上方「匯出盤面 JSON」保存成果，之後可用「匯入盤面 JSON」還原或分享給其他使用者，詳見 [快照格式與使用方式](board-snapshot.md)。重新整理會清除本頁接線，請先匯出。匯入會替換目前盤面，完成後保持未送電；檔案不相容或路徑損壞時保留原盤面。下載 HTML 與網站使用同一份 WIRE-R12 原始碼。
