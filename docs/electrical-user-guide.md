# WIRE-R16 電路模擬操作

此模擬用於離散教學。負載額定值及保護時間未完整核對；TH 的 TC–TB／TC–TA 採既有教學設定。

## 課堂 BOARD-024

1. 使用「匯入盤面 JSON」載入 `examples/board-024-classroom.project.json`。匯入會重建配線，完成後保持配線模式；操作板收合、QF1 OFF。
2. 按「開始測試」，將 QF1 切到 ON，再按綠色 PB3。綠燈 HL4 亮，放開 PB3 後繼續亮。
3. 按紅色 PB5，MC1 釋放、綠燈熄滅。放開 PB5 不會自行重啟。
4. 再按 PB3 啟動，操作 TH1 TEST：綠燈熄滅，紅燈與蜂鳴器動作。RESET 後警報解除，仍須再按 PB3 才會啟動。
5. 運轉時將 QF1 切到 OFF，控制輸出停止；再切 ON 且未按 PB3，應維持停止。

此檔保留原始 22 條控制配線；MAIN L1/L2/L3 到 QF1 L1/L2/L3 的三條電源線已納入設備固定配置，不需要自行接線。MC1 左右側 APS-11 分別用於自保與綠燈；AP1 不接線。未接完整馬達主回路，因此不能由綠燈亮推論 M1 已獲得三相供電。

若匯入原始 BOARD-024，程式會辨識原盤配置並補上設備預接線；舊版已手動接好的相同三條進線會歸入固定配置，其餘端點保持原樣。新建預設盤同樣已預接，QF1 初始 OFF；請從 QF1 的 T1/T2/T3 出線端開始練習。右側「固定預接線與銅片」可查看連接，練習線的刪除與復原不會移除它們。

## 端子辨識

| 元件 | 接點配對 | 動作 |
|---|---|---|
| PB1–PB5 | 2／3 為常開 NO，1／4 為常閉 NC | 按下使 NO 通、NC 斷；放開復歸 |
| MC1 左側 APS-11 | L-B-L／L-F-L 為 NO，L-B-U／L-F-U 為 NC | 隨 MC1 線圈吸合切換 |
| MC1 右側 APS-11 | R-B-L／R-F-L 為 NO，R-B-U／R-F-U 為 NC | 隨 MC1 線圈吸合切換 |
| AP1 上方模組 | 53／54、83／84 為 NO；61／62、71／72 為 NC | 隨父接觸器吸合切換 |

按鈕的數字是程式穩定端子 ID。預設盤面展開操作板並歸正視野後，2／3 在畫面左側、1／4 在右側；旋轉視野或更改安裝方向後，應以端子 ID 和接點標示為準。每側 APS-11 的低層前後兩端為 NO，高層前後兩端為 NC。

舊版的按鈕對角配對已校正。匯入不會偷偷換線：依舊版對角規則製作的其他專案，需要依新版標示重新核對；原始課堂 BOARD-024 的端點則保持原接法。

## 完整 A04 與一般操作

`examples/a04-motor-start.project.json` 包含馬達主回路，使用同一外接三相來源；AP1 的自保／指示接點仍可使用。該範例已同步校正 PB 配對，QF1 初始 OFF。MC1 到 TH1 的三條固定組裝銅片已明示列出，不需重複加線。

修改、刪除或新增接線前，先返回配線模式。可從「供電原因與端子定位」查看導通網路與相關電線；高亮包含分支，不代表電流方向。短路或未知模型會停止運算，需要返回配線、修正後重試。

指示燈的亮光在操作板正面，請收合後查看。選中的導線以桃紅色提示，其他線淡化；系統偏好減少動態效果時保留顏色差異並停用閃爍。

用「匯出盤面 JSON」保存接線與配置，重新整理前請先匯出。匯入失敗會保留原盤面；成功匯入後不自動開始測試。網站與下載 HTML 共用 WIRE-R16 原始碼。專案格式見 [project-format.md](project-format.md)。
